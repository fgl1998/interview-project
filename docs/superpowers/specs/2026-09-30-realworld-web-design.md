# RealWorld Web 设计

用户已选择 Vue 3 + TypeScript + Vite + Element Plus，并明确要求开始开发。新项目位于 `realworld-web`，直接在用户指定工作区开发，保留现有 uni-app 和 Java 项目。实现工作由当前会话完成，最终进行独立代码审查；无需重复技术栈审批。

## 目标与范围

提供以桌面浏览器为主、兼顾移动浏览器的中文文章社区。复用 Java 后台的登录、注册、文章分页搜索、文章详情、标签、发布、删除、收藏、评论、作者主页、关注关系和编辑个人资料接口。Java 暂无文章更新接口，因此本期不提供已发布文章编辑。智能助手依赖单独的 Agent 服务及旧鉴权链路，本期不迁移该服务。

## 页面与视觉

顶部品牌导航、写文章入口和账户菜单；首页采用文章列表与标签侧栏，顶部有社区介绍，留白充足。颜色为深青、浅灰和白，Element Plus 使用统一主题色。登录注册采用双栏页面；文章详情提供正文、作者信息、收藏及评论；个人主页提供文章、关注和粉丝标签页，自己的主页增加收藏。资料页用户名禁用，允许邮箱、简介、头像 URL 和可选密码。提供加载、空状态、可重试错误、404 以及确认删除。

## 数据与安全边界

Vue Router 使用 history，Pinia 管理会话，Axios 同源 `/api`。开发代理目标默认 `http://127.0.0.1:8080`，允许环境变量覆盖，生产通过 Nginx 代理。Java 除登录注册外所有 API 均需鉴权：未登录首页展示登录引导，业务页面需登录，保存站内重定向。统一解析 `{success,code,message,data}`，HTTP 401 和业务 401 均清理对应会话；旧请求的 401 不清理新会话。请求超时和网络错误可读，不缓存密码。资料更新严格白名单，ID 来自会话，空密码不传。文章作者查询显式传 authorId，包括当前用户。正文以 Markdown 渲染且禁用 HTML，拦截危险链接，不执行用户 HTML。

路由变化时忽略旧加载结果；保存期间阻止重复提交。收藏成功后更新本地状态，失败保持原状态。只有本人文章和评论显示删除入口。主页收藏仅自己可见，其他作者的文章保持入口。会话变更不会把旧用户的加载或保存结果写入新用户会话。

## 验收

严格类型检查、ESLint、业务单元测试、核心页面组件测试、浏览器完整业务流程测试和生产构建均通过。浏览器自动测试以独立模拟 Java HTTP 边界运行，不写入真实数据库；另外探测本机真实后台连通性，结果据实说明。交付包含锁文件、启动指令、环境示例、生产 Nginx 示例。
